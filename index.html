Informazioni e guida

                                    
Contesto, architettura e modalità di utilizzo dell'applicazione.

                                

                            


                            

                                

                                    
Finalità

                                    
L'applicazione supporta il censimento degli asset, la lettura delle dipendenze, la tracciabilità delle modifiche e la classificazione guidata degli incidenti.

                                

                                

                                    
Architettura

                                    
Frontend HTML5, CSS e JavaScript modulare pubblicato su GitHub Pages, integrato con Supabase per autenticazione, MFA, API dati e policy RLS.

                                

                                

                                    
Sicurezza

                                    
L'accesso ai dati è controllato tramite sessione autenticata, livello AAL, privilegi PostgreSQL e Row Level Security.

                                

                                

                                    
Project Work

                                    
Progetto sviluppato per il corso di Informatica per le aziende digitali (L-31), con impostazione generale e non vincolata a uno specifico settore produttivo.
